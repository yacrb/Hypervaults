# Artwork sources

Python, FastAPI, MongoDB, Ethereum, Docker and Solidity SVGs come from
[Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons).
The artwork is provided under [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
Each brand retains its separate trademark rights and usage guidelines. The marks
identify technologies used by HyperVaults; they do not imply endorsement.

The HyperVaults logo is copied from `webapp/static/favicon.svg`. The cover
illustration is rendered directly from `webapp/static/vault.svg`.
Diagram line icons and layouts are native SVG paths defined in `diagrams.py`.
Report rendering recolors technology marks purple without changing their paths.
